## Задание 1 Письменно ответьте на следующие вопросы (ответы формулируйте кратко и по существу):

# 1. Из каких основных компонентов состоит стандартный HTTP-запрос?
Ответ: HTTP-запрос состоит из следующих компонент:
1. Стартовая строка (start line):
[Метод] [URL] [HTTP/версия].
2. Заголовки (headers). Имеют формат:
1) Пустая строка;
2) Опциональное тело сообщения.

# 2. В чем фундаментальное различие между статус-кодами класса 4xx и класса 5xx?
Ответ: Фундаментальное раздичие между статус-кодами класса 4xx и 5xx состоит в том, что статус-код класса 4xx говорит об ошибке на стороне клиента (например, некорректный запрос), а 5xx говорит об ошибке на стороне сервера.

# 3. Что содержит первая строка (стартовая строка) HTTP-ответа?
Ответ: Стартовая строка HTTP-ответа состоит из следующих компонент:
[HTTP/версия] [Код_состояния] [Пояснения]

# 4. Для чего предназначен заголовок Content-Type в HTTP-сообщении?
Ответ: Заголовок Content-Type в HTTP-сообщении предназначен для указания формата данных в документе и кодировки символов в нем.

4. Выполните HTTP-запрос из предыдущего задания в браузере. Каков будет результат?

Ответ:

```Code
from requests import get

SUCCESSFUL_STATUS_CODE = 200
CLIENT_ERROR_CODE = 404
SERVER_ERROR_CODE = 500
params = {
    "ll": "30.314494,59.938676",
    "spn": "0.016457,0.00619",
    "l": "map"
}
response = None

try:
    response = get("https://static-maps.yandex.ru/1.x/", params = params)
except response.status_code == CLIENT_ERROR_CODE:
    print("Некорректный запрос!")
except response.status_code == SERVER_ERROR_CODE:
    print("Ошибка на стороне сервера.")
except response.status_code != SUCCESSFUL_STATUS_CODE:
    print("Не удалось сохранить изображение.")
else:
    with open("my_place.png", "wb") as file:
            file.write(response.content)
    print("Изображение карты сохранено в файл my_place.png.")
```
